# 回测报告

HarmonicCycleLab 择时回测结果。数据在 `docs/data/backtest_master.json`，可用 `scripts/run_backtest_ablation.py` 重跑。

## 方法

策略在每个交易日收盘后构造四个分量得分，落在约 \([-1, 1]\)：

- **TD**：近期 TD9 买/卖信号，按半衰期衰减
- **Cycle**：对历史窗口做去趋势谐波拟合，用未来投影斜率判断上/下；接近投影峰时略作减分
- **CMF**：短窗资金流（CMF），经 tanh 压缩
- **SuperTrend**：价在带上为 +1，带下为 −1

综合得分：

```text
score = w_td·TD + w_cycle·Cycle + w_cmf·CMF + w_st·SuperTrend
```

若 `score ≥ threshold`，下一根 K 线收盘做多，否则持有现金（只做多、不做空）。单侧交易成本按 5 个基点计入换手。

周期长度有两种来源：

| 设定 | 含义 |
|---|---|
| 固定周期 | 始终使用默认 `[127, 227, 78]` 个交易日 |
| DFE | 每次刷新时在近窗残差上用 periodogram 自动抽取三个主导周期 |

**网格最优**：在权重单纯形上搜索（并局部细化），按样本内夏普比率取最优。  
**仅周期**：权重固定为 Cycle=100%，只扫描阈值。

公共参数：Yahoo Finance 日线；起点约 2014（XLC / XLRE 上市更晚）；warmup 400 根；拟合 lookback 505 根；周期得分每 5 根刷新一次。买入持有基准与策略共用同一评估窗口，自 warmup 结束后起算。

## 注意

网格权重是在同一样本上选出来的，「最优」行偏乐观。看各标的/设定的相对排序即可，别把某一格总收益当成实盘预期。

## 讨论

1. 多因子网格整体优于单独的周期投影；周期更适合作为相位确认，而不是唯一仓位开关。
2. DFE 对部分板块有帮助，但对全部 ETF 并非一致增益，部署时仍宜保留固定默认周期作为对照。
3. 在长期强趋势宽基（如 QQQ、VOO、XLK）上，空仓会牺牲大量绝对收益，即使夏普偶尔更好。
4. 能源、小盘、部分利率敏感板块更常出现「择时总收益可超过买入持有」的情形，与弱趋势、深回撤的价格路径一致。

后续若要降低过拟合风险，建议按 `docs/improvement-roadmap.zh.md` 做滚动样本外验证，并报告交易成本与滑点敏感性。
